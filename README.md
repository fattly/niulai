# 牛来 · 全网在线召牛挑战

> 喊得越狠，来的牛越猛。

10 秒极限点击，召唤属于你的牛。每头牛有重量、时速、撞击力属性，根据得分决定等级（F ~ SSS）。

## 灵感来源

本作灵感来自 2026 年 8 月爆火的国产动画电影 **《牛来》**。

这部成本仅约万元的小众动画，上映初期票房惨淡（首日仅 342 元、多日累计不过几千元），却在一条"烂到极致"的吐槽视频刷屏后**反向爆火**：单日票房一度暴涨超 300 倍，话题冲上热搜第一，猫眼预测总票房一度冲向 1837 万。

"喊得越狠，来的牛越猛"正呼应了这部电影"越吐槽越出圈"的荒诞走红——人人都忍不住吼一句"牛来"，看看自己到底能召唤出多猛的牛。

## 快速开始

直接打开 `index.html` 即可游玩，无需构建工具。

## 游戏规则

- 10 秒倒计时内疯狂点击，每次点击增加 1 分
- 连击 Combo 会带来额外速度加成
- 最终得分决定牛的等级和外观

## 项目结构

```
niulai-simulator/
├── index.html        # 单页应用（HTML + CSS + JS）
├── images/
│   ├── home-hero.webp    # 首页主视觉
│   ├── crash-bull.webp   # 结算页牛图雪碧图
│   ├── level_list.webp   # 等级展示雪碧图
│   ├── run.webp          # 奔跑动画雪碧图（9 帧）
│   └── run.png           # 手机 WebView 兼容兜底
└── audio/
    └── cow.mp3           # 牛叫声
```

## 技术特点

- 纯原生 HTML/CSS/JS，零依赖
- 等级雪碧图逐格裁切，适配不同等级
- 奔跑动画 9 帧可交互画布，跟随点击节奏变速
- 战绩分享卡片支持 SVG 二维码（真实可扫，指向 `https://niulai.fattly.cn/`）
- Canvas 导出 2x 高清战绩海报
- 访问统计：百度统计 + vaefamily
